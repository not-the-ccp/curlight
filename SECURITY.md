# Security policy

curlight is currently alpha software. No long-term supported release exists yet;
security fixes target the main branch.

Report vulnerabilities privately using GitHub's **Report a vulnerability** feature:
https://github.com/not-the-ccp/curlight/security/advisories/new

Do not disclose credentials or sensitive URLs in public issues. Include libcurl
version, Python version, backend, operating system, and a minimal reproducer using
local/test data. Security of TLS/protocol implementations also depends on your
system libcurl; keep it and its dependencies patched.
